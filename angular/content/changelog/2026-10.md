## Updated

- **All components**: Every component folder is its own entry point, such as `@angel-r/fluid-functionalism-angular/calendar`, so an app bundles only the components it imports. The bare package name still exports everything, but `@defer` splits a component out only when it is imported from its sub-path. (#5)
