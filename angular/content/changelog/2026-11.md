title: VirtualScroll, and autofilled fields that keep their look
---

Changes only the Angular port has.

## New

- [VirtualScroll](/docs/virtual-scroll): Renders only the rows and columns in view, plus a buffer, so a 10,000-row table or a time matrix with hundreds of columns stays light. Nest an `axis: 'x'` window inside the rows to virtualize both axes; inside an `ff-table` it keeps the table's semantics and its fluid hover. (#15)

## Updated

- [Calendar](/docs/calendar): A `timeZone` input reads the days, today and every date it is given in one IANA zone, whatever the browser's, and hands each day out as the instant it starts there. (#14)
- [DatePicker](/docs/date-picker): A `timeZone` input picks days in one IANA zone, whatever the browser's: in `"UTC"` a picked day serializes as `2026-10-21T00:00:00.000Z`, and a named picker submits each time with the zone's offset. (#14)
- [InputGroup](/docs/input-group): A field the browser autofills keeps its own look, with no second square box inside the rounded field, at rest, focused and through a theme change. (#13)
- **Icon packs**: Every icon is its own export, named for its slot, such as `phosphorCheck` from `@angel-r/fluid-functionalism-angular/icon-packs/phosphor`, so an app that swaps a few slots bundles those glyphs alone instead of the whole pack (9 to 46 KB minified). The pack maps such as `phosphorIcons` still work. (#16)
