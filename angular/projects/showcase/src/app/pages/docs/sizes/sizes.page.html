Two component sizes: a 36px default and a 28px compact. Press S to toggle on the website.

An interface reads as one product when its controls share a sizing rhythm. A button next to a select next to a tab should land on the same height.

Each size scales text, icons, and padding together.

Compact is for dense, data-heavy tools; default is the right call for everything else.

Type follows the ladder. Compact drops each of the six roles one notch, size and leading together, so a dense screen keeps the same hierarchy at a smaller size. The full scale lives on Typography.

Density is a region decision, not a per-control one. Wrap the region in [ffSizeProvider] and everything inside follows — menus included, since the size context crosses overlays.
